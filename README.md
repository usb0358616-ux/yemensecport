# نظام المنافذ والجوازات الذكي (Smart Ports and Passports System)

نظام متكامل واحترافى مصمم لإدارة حركة المسافرين عبر المنافذ، وتسهيل عمليات المباينة الأمنية، وإدارة بلاغات الضبط، واستخراج الإحصائيات الدقيقة.

## نظرة عامة (Overview)
يهدف هذا المشروع إلى توفير أداة رقمية قوية لموظفي المنافذ والجوازات للتعامل مع البيانات الضخمة للمسافرين بكفاءة عالية. يتميز النظام بواجهة مستخدم عربية بالكامل، ودعم للطباعة الرسمية، والقدرة على استيراد البيانات من ملفات Excel.

## المميزات الرئيسية (Key Features)
- **إدارة المسافرين**: إضافة وتعديل بيانات المسافرين مع دعم لرفع الصور الشخصية والمرفقات (PDF/صور).
- **المباينة الأمنية الذكية**: استيراد كشوفات المباينة من ملفات Excel ومطابقتها تلقائياً مع سجلات المسافرين.
- **بلاغات الضبط**: نظام لإدارة وتوثيق بلاغات الضبط الأمنية.
- **الإحصائيات والتقارير**: لوحة تحكم تعرض مؤشرات الأداء وإحصائيات المسافرين والممنوعين من السفر.
- **الطباعة الرسمية**: توليد استمارات رسمية جاهزة للطباعة بترويسة وزارة الداخلية.
- **دعم كامل للغة العربية**: واجهة مستخدم متوافقة مع اتجاه النص من اليمين إلى اليسار (RTL).

## التقنيات المستخدمة (Tech Stack)
- **Frontend**: React 19 + TypeScript
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui + Radix UI
- **Icons**: Lucide React
- **Data Processing**: XLSX (SheetJS)
- **Routing**: React Router Dom
- **Animations**: Framer Motion

## تعليمات التشغيل (Setup & Running)

### المتطلبات الأساسية
- Node.js (إصدار 18 أو أحدث)
- npm أو yarn

### التثبيت
1. قم بتثبيت التبعيات:
   ```bash
   npm install
   ```

### التشغيل في بيئة التطوير
1. ابدأ خادم التطوير:
   ```bash
   npm run dev
   ```
2. افتح المتصفح على الرابط `http://localhost:3000`.

### بناء المشروع للإنتاج
1. قم بإنشاء نسخة الإنتاج:
   ```bash
   npm run build
   ```
2. سيتم إنشاء الملفات في مجلد `dist`.

### تحويل المشروع إلى برنامج Windows (EXE)
تم إعداد المشروع ليعمل كبرنامج مستقل باستخدام **Electron**. للحصول على ملف `exe`:
1. قم بتحميل المشروع كملف ZIP من قائمة الإعدادات.
2. فك الضغط وافتح المجلد في Terminal.
3. قم بتثبيت التبعيات: `npm install`.
4. قم ببناء البرنامج:
   ```bash
   npm run electron:build
   ```
5. ستجد ملف البرنامج الجاهز في مجلد `release`.

## التبعيات (Dependencies)
النظام يعتمد على مجموعة من المكتبات الحديثة لضمان الأداء والاستقرار، منها:
- `react`, `react-dom`: المكتبات الأساسية لواجهة المستخدم.
- `lucide-react`: للأيقونات التفاعلية.
- `xlsx`: لمعالجة ملفات Excel.
- `sonner`: للتنبيهات المنبثقة.
- `react-router-dom`: لإدارة التنقل بين الصفحات.
- `clsx`, `tailwind-merge`: لإدارة فئات CSS بكفاءة.
